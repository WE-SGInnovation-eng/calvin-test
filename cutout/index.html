How it works

  1. Drop

    Pick any photo. It stays in this tab — nothing is uploaded to a server.

  2. Separate

    An open-source segmentation model (ISNet) runs on your device and builds an alpha mask around the subject.

  3. Download

    The mask becomes the image’s transparency. You get a PNG ready for decks, listings or thumbnails.

Built on @imgly/background-removal and ONNX Runtime Web. First run fetches the model; after that it works from cache.
